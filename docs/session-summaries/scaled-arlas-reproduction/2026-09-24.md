## Decisions and rationale

1. **Keep Qwen3-4B as the provisional model baseline.** It is the first screened
   Qwen model to pass benign competence and tool-validity gates, while fitting
   comfortably on the RTX 4090.
2. **Use Slack only for the scaled static reproduction.** Its attack signal is
   nonzero and its attacked utility remains usable, but intervention depth is
   too shallow for long-horizon or attacker-memory claims.
3. **Do not begin RL yet.** The standalone injection-goal capability gate and
   the intervention-depth gate failed.
4. **Do not relax failed thresholds after seeing results.** A future repair
   screen must use a newly frozen manifest and be labeled exploratory or
   confirmatory as appropriate.
5. **Keep model-family comparisons bounded.** If needed, screen
   `HuggingFaceTB/SmolLM3-3B` first because it has a native Hermes-style tool
   format, then `meta-llama/Llama-3.2-3B-Instruct` after accepting its gated
   license. Qwen3-4B remains the current working baseline.
6. **Do not require attacker and defender to share one GPU.** A second machine
   has two GPUs. Future training configuration should allow independent device
   assignment and portable cache/data paths.

## AgentDojo mental model

The legitimate user task is sent as the user message. An injection goal is
inserted into environment data (webpage, Slack channel name, blog, restaurant
content, and so on) and reaches the model through a tool response. The model is
not given an explicit `injection_task` label; it must distinguish trusted user
instructions from untrusted tool data by provenance. Standalone injection-goal
episodes are auxiliary capability checks, not attacked episodes.

To inspect Slack prompts:

```bash
/data/adversarial_agent/.venv/bin/python - <<'PY'
from agentdojo.task_suite.load_suites import get_suite

suite = get_suite("v1.2.2", "slack")
for task_id, task in suite.user_tasks.items():
    print(f"{task_id}: {task.PROMPT}")
for task_id, task in suite.injection_tasks.items():
    print(f"{task_id}: {task.GOAL}")
PY
```
